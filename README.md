# Vehicle Rental Management System

## 1. Project Overview

The Vehicle Rental Management System is a DBMS mini-project
developed to manage vehicle rental operations using SQL and SQLite.

The system stores customer details, vehicle information,
rental records, and payment information.

## 2. Objectives

- Store and manage customer information.
- Maintain vehicle details.
- Track vehicle rental records.
- Manage payment information.
- Retrieve records using SQL queries.
- Demonstrate database operations.

## 3. Technologies Used

- Database: SQLite
- Query Language: SQL
- Development Environment: Visual Studio Code
- Database File: vehicle_rental.db

## 4. Project Files

- Vehicle_Rental_Management_System.sql
- vehicle_rental.db
- Report/Vehicle_Rental_Management_System_Report.pdf

## 5. Database Operations

The project demonstrates:

- CREATE TABLE
- INSERT
- SELECT
- UPDATE
- DELETE
- WHERE conditions
- ORDER BY
- GROUP BY
- Aggregate functions
- JOIN operations
- Subqueries

## 6. How to Run the Project

1. Download or clone this repository.
2. Open the project in Visual Studio Code.
3. Open the SQL file.
4. Connect to vehicle_rental.db using an SQLite extension.
5. Execute the SQL queries using the SQLite extension.

## 7. Project Output

The database contains customer, vehicle, rental, and payment
records that can be retrieved using SQL queries.

## 8. Conclusion

This project demonstrates how a database management system
can be used to organize and retrieve vehicle rental information.
